# Kailash Hospital website

Responsive single-page bilingual website draft. Main file: `index.html`.

## Publish using GitHub Pages
1. Create a **new public repository** named `kailashhospital` in your GitHub account.
2. Upload `index.html` to the repository root and commit it.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. After deployment, the URL format is `https://YOUR-GITHUB-USERNAME.github.io/kailashhospital/`.

## Before public launch
- Replace the temporary text logo with the official hospital logo.
- Add verified hospital and doctor photographs.
- Verify current doctor roster, qualifications, timings and listed facilities.
- Confirm the map pin is the exact hospital entrance.
- Add privacy and regulatory disclosures as appropriate.

The site is a static information and WhatsApp enquiry page; it does not store patient data or provide online diagnosis.
